# Sem autenticação: seletor de perfil

O protótipo não tem login. A interface oferece um seletor de perfil (Coordenação / Discente) que troca a navegação. Como nenhum dado pessoal é persistido (ADR 0003) e o PPC é público, não há o que proteger por identidade no escopo do prêmio. Integração com SIGAA/SSO da UFC fica descrita como trabalho futuro. Quem adicionar autenticação deve revisar esta decisão junto com a política de retenção de trajetórias.
